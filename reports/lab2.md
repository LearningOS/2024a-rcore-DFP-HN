# Lab2报告
## 实现的功能
+ 实现了申请长度为 len 字节的物理内存，将其映射到 start 开始的虚存，内存页属性为 port。确保参数合法，指定区间虚存没有分配，且有足够内存时才进行映射。
+ 取消到指定区间虚存的映射，参数合法，所有虚拟页号对应的页表项有效时，才会回收内存。
+ 实现了sys_get_time和sys_task_info在引入虚存机制后仍然能够正常工作，对于结构体中成员在不同的虚拟页中也能正常工作。


# 问答作业
1. SV39 页表页表项的组成：物理页号，读、写、执行权限标志位，访问位，有效位，脏位，U特权位。
2. 缺页导致的情况：a. 访问未映射的虚拟地址。 b. 访问页表项有效位为0的虚拟地址。 c. 栈溢出 发生缺页时，重要的寄存器有堆栈寄存器，异常向量寄存器，程序计数器，页表基址寄存器，状态寄存器。 Lazy策略能够减少应用运行时占用内存的大小。 处理 10G 连续的内存页面，需要20MB的页表项，需要5120个页面。 在访问虚拟地址时，在页表找不到对应的物理地址，则发起缺页中断，进入缺页的中断处理程序，进行分配物理内存。 内存页面被换到磁盘上，导致对应页面失效，PTE的有效位置0。
3. 单页表情况下，保存当前上下文，更新satp。在页表项设置一个U标志位，如果U=1，则用户不能访问该页面，如果为0，则可以。单页表管理更简单，内存开销小。 双页表实现下，用户线程切换到内核线程时更换页表。单页操作系统在切换进程时切换页表。
